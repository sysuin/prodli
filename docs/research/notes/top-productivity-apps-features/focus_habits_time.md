# Most-used features of leading focus, blocking, habit and time-tracking apps (2025–2026)

Context for the reader: the target product is an all-in-one Chrome extension that already has a Pomodoro timer, daily habits with streaks, and a per-website time tracker with daily per-site limits. Research date: November 2026. Budget allowed ~16 tool calls, so coverage of 22 apps is uneven. Many figures come from third-party roundup blogs, some written by competing vendors. Each is flagged where relevant.

## Q1. User numbers or rank, and which features users rely on most (per app)

### Takeaway
The only hard install counts available are Chrome Web Store numbers: BlockSite about 1M users and StayFocusd about 700K (Oct 2026), LeechBlock NG 100K. All mobile and desktop user figures are self-reported or come from third parties. In blockers the most relied-on features are daily usage limits, schedules, a "locked"/nuclear mode that can't be cancelled, and in-page hiding (e.g. YouTube Shorts). In habit apps they are flexible habit types (count, timed, negative), Health auto-logging, and heatmaps/stats. In time trackers they are passive automatic tracking with a focus score and productive/distracting categorization.

### Cited Findings

**Browser blockers (most comparable to the target product)**
- BlockSite: ~1,000,000 Chrome Web Store users, 4.5★ from 32.4K ratings, v7.1.1 updated July 26, 2026, 17 languages (store data as of Oct 2026) — [SiteKeeper comparison](https://www.sitekeeper.tech/compare/stayfocusd-vs-blocksite)
- BlockSite features: Usage Limit (daily cap, then blocked for rest of day), Schedule Mode, Focus Mode (Pomodoro), keyword blocking synced to mobile, site redirect, password protection and uninstall prevention, "Insights" (browsing trends and categories), Android/iOS sync. Free plan: limited blocking, manual only, 1 device, no scheduling. Paid: $33.50/yr, $49.90 lifetime (checked Oct 3, 2026) — [SiteKeeper](https://www.sitekeeper.tech/compare/stayfocusd-vs-blocksite)
- StayFocusd: ~700,000 Chrome Web Store users, 4.4★ from 8.8K ratings, v4.6.15 updated Oct 2026 — [SiteKeeper](https://www.sitekeeper.tech/compare/stayfocusd-vs-blocksite). The vendor's own site claims 2M+ users, which conflicts with the store figure — [StayFocusd](https://www.stayfocusd.com/), per [search summary](https://www.sitekeeper.tech/compare/stayfocusd-vs-blocksite)
- StayFocusd features: one shared daily time budget per block group, "Nuclear Option" that "cannot be canceled once it starts", "Require Challenge" to gate settings changes, Active Days/Hours scheduling, in-page hiding of YouTube Shorts, comments and recommendations, path and page-level blocking, daily usage stats, and "Gen AI analytics for AI chat platforms". Syncs limits with Android. Free, including Nuclear Option. Not offered: weekly limits, Pomodoro, 0–100 score — [SiteKeeper](https://www.sitekeeper.tech/compare/stayfocusd-vs-blocksite)
- One blog reported a sharp drop in recent StayFocusd reviews, attributed to a block-list bug and privacy concerns. This comes from a single third-party crawl and is unverified — [web-highlights blog via search](https://web-highlights.com/blog/best-website-blocker-chrome-extensions/)
- LeechBlock NG: 100,000 Chrome Web Store users, 4.9★ from ~1.5K ratings — [Chrome Web Store](https://chromewebstore.google.com/detail/leechblock-ng/blaaajhemilngeeffpbfkdjjoefldkok?hl=en). Free and open source, browser-only. Users describe it as "customizable" and "privacy focused" — [AlternativeTo](https://alternativeto.net/software/cold-turkey)

**System-level blockers**
- Cold Turkey: described as the strictest conventional blocker. Its lockout mode restricts the whole computer to a whitelist, and its lock blocks make bypassing "almost impossible". Source is a competitor (FocusJar) plus AlternativeTo — [FocusJar](https://focusjar.app/articles/best-website-blockers-for-adhd); [AlternativeTo](https://alternativeto.net/software/cold-turkey). It has a free tier — [Asian Efficiency](https://www.asianefficiency.com/productivity/best-focus-deep-work-apps/)
- Freedom: locked mode ("Once a session starts, you can't end it early. Even restarting your computer won't help."), scheduled recurring sessions, custom blocklists, cross-device sync (Mac, Windows, iOS, Android, Chrome). The iOS app uses a VPN configuration. $8.99/mo, $39.99/yr, $199 lifetime. No user count published — [Asian Efficiency](https://www.asianefficiency.com/productivity/best-focus-deep-work-apps/)
- **Usage and efficacy evidence (Freedom, 2025):** a preregistered RCT in PNAS Nexus (Castelo et al., Feb 2025) used Freedom to block mobile internet for 2 weeks. 467 adults committed, 266 actually installed the app, and only 119 (25.5%) met the compliance definition. Compliers improved in well-being, mental health and sustained attention (gradCPT). Some gains faded after blocking ended — [PNAS Nexus](https://academic.oup.com/pnasnexus/article/4/2/pgaf017/8016017); [PsyPost](https://www.psypost.org/want-better-focus-and-a-happier-mind-this-simple-smartphone-change-could-be-the-answer/). Implication: setup friction and drop-off are large even for motivated users.

**Mobile screen-time and friction apps**
- Opal: self-reported "500 million hours of screen time saved" as of Aug 2026, up from 200M as of May 2025 — [App Store](https://apps.apple.com/us/app/opal-screen-time-control/id1497465230); [Opal blog](https://opalapp.com/blog/opal-saved-over-100-million-hours-worldwide-from-screens). A 2026 third-party review cites 4M users and $10.3M ARR (unverified) — [Headway review](https://makeheadway.com/blog/opal-app-review/). Funding figures conflict: $4.3M per [Tracxn](https://tracxn.com/d/companies/opal/__H3T1WQbpF7IZMFOTKo5l7I-uOcPLbCPSvEH33X9QxJI) vs $11.8M per the 2026 review.
- Opal features: scheduled sessions, deep iOS Screen Time integration, detailed usage analytics — [unstar.app](https://unstar.app/blog/opal-forest-freedom-one-sec-jomo-screen-time-apps-ranked-2026). "Focus Report" benchmarks you against peers — [App Store](https://apps.apple.com/us/app/opal-screen-time-control/id1497465230). Gamification: 21 "Focus Gems" for milestones, seasonal achievements, leaderboards, co-working sessions — [screensdesign](https://screensdesign.com/showcase/opal-screen-time-control). ~$100/yr. Strong on iPhone, limited or absent on Android, weak on Mac — [habi.app](https://habi.app/insights/best-screen-time-apps/); [tryhugo](https://www.tryhugo.app/blog/opal-app-review-2026)
- One Sec (friction/pause screen): **the best usage evidence in this category.** A 2023 PNAS field study (N=280, 6 weeks; older than the 2025–26 window, and the founder is a co-author) found: 36% of attempted opens were abandoned after the pause screen; attempted opens fell 37% from week 1; actual target-app opens fell 57% after 6 weeks — [PNAS/PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC9974409); [one sec research page](https://one-sec.app/max-planck-study)
- One Sec mechanism finding: in a preregistered online experiment (N=500), giving users an explicit option to dismiss/close the attempt had the strongest effect. A time delay alone also helped, but a deliberation message alone was "not effective" — [PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC9974409)
- One Sec has no hard-block mode, and users can wait out or skip the breathing prompt — [unhookd](https://unhookd.app/blog/social-media-blocker-comparison); [habitdoom](https://habitdoom.com/blog/best-app-blockers-for-students)

**Gamified focus timers**
- Forest: tree grows during a session and withers if you leave the app. Coins unlock species and soundscapes or fund real trees (>2 million real trees planted via Trees for the Future). "Time Guard" blocks apps and tracks screen time. Chrome and Firefox extensions exist. Launched May 2014 as paid; Dec 2025 moved to free download plus "Forest Plus" subscription — [Wikipedia](https://en.wikipedia.org/wiki/Forest_(application)). No user count found.
- Reviewers call Forest's blocking weak: it is session-based and you can just let the tree die — [unstar.app](https://unstar.app/blog/opal-forest-freedom-one-sec-jomo-screen-time-apps-ranked-2026)

**Pomodoro / session apps (Mac)**
- Session: intention-setting before a session, reflection step after it, a day/week log and analytics (Pro), macOS Focus/iPhone Do Not Disturb integration, app and website blocking, and an "overflow" mode that lets you keep going past the timer — [Asian Efficiency Pomodoro](https://www.asianefficiency.com/productivity/best-pomodoro-timer-apps/); [Zapier](https://zapier.com/blog/best-pomodoro-apps/); [apps.deals](https://blog.apps.deals/best-pomodoro-timer-apps-mac)
- Flow: minimalist. "Commitment Mode" hides the stop button until the timer ends. Pro adds custom cycles and titles, app/website blocking during sessions, Apple Calendar sync and export — [apps.deals](https://blog.apps.deals/best-pomodoro-timer-apps-mac); [publicspace.net](https://www.publicspace.net/focus/best-pomodoro-apps-mac/)

**Focus sounds**
- Brain.fm: AI-generated "functional audio", infinite/countdown/interval timers, more than 1,000 hours of content, no free tier (7-day trial). Claims "119% increase in focus-associated beta brainwaves" from its own research (marketing claim) — [Asian Efficiency](https://www.asianefficiency.com/productivity/best-focus-deep-work-apps/)
- Endel: adaptive soundscapes driven by time of day, weather, heart rate (Apple Watch) and location. Focus/relax/sleep/activity modes. Free tier allows unlimited 10-minute sessions — [Asian Efficiency](https://www.asianefficiency.com/productivity/best-focus-deep-work-apps/); [getseam](https://getseam.app/blog/brain-fm-alternative)
- Forest also sells soundscapes via coins, so ambient sound shows up inside gamified timers too — [Wikipedia](https://en.wikipedia.org/wiki/Forest_(application))

**Body doubling**
- Focusmate: positioned as human accountability ("Accountability that feels human"). No usage data found — [reclaim.ai](https://reclaim.ai/blog/focus-apps). Opal also lists "co-working sessions" among its features — [screensdesign](https://screensdesign.com/showcase/opal-screen-time-control)

**Automatic time trackers**
- Rize: passive automatic tracking; daily focus score out of 100 that separates deep focus from shallow work and meetings; shows top interruptions; break reminders triggered by actual focus time rather than a clock; Pomodoro-style timer; distraction blocker with a 10-second "urge-surfing" delay before blocked sites open — [dhruvirzala review](https://dhruvirzala.com/rize-review/); [Rize vs RescueTime](https://rize.io/blog/rize-vs-rescuetime). Product Hunt: 4.9 from ~17 reviews, praising accurate passive tracking, focus and distraction insights, break prompts, background audio and reports — [Product Hunt](https://www.producthunt.com/products/rizeio/reviews). Basic plan $9.99/mo billed annually — [toolradar](https://toolradar.com/tools/rize)
- RescueTime: automatic activity tracking with daily goals, alerts when too much time goes to distracting activity, and automations — [Timing blog](https://timingapp.com/blog/rescuetime-alternatives/). Author is a competitor.
- Toggl Track: idle detection, Pomodoro reminders, background "autotrack" triggers from open apps and calendar meetings, entry suggestions — [aicentralresources](https://www.aicentralresources.com/blog/timely-vs-rescuetime-vs-toggl-best-ai-time-tracker-in-2026); [usecarly](https://www.usecarly.com/blog/best-ai-tools-time-tracking/). One review disagrees and calls it "primarily manual" — [aicentralresources](https://www.aicentralresources.com/blog/8-best-ai-time-tracking-tools-in-2026-compared-priced-honestly-ranked)
- Clockify: low-cost and mostly manual project time logging. Its auto-tracker is less specialized than RescueTime's, and its AI is minimal — [trakkr](https://trakkr.ai/ai-analysis/clockify-vs-rescuetime-ai-analysis); [timely](https://www.timely.com/blog/toggl-track-alternatives/)

**Habit trackers**
- Habitica: third-party figures of 4M+ (Google Play) and "15M+ downloads", which conflict — [2sync](https://2sync.com/blog/best-habit-tracker-apps); [launchlify](https://launchlify.com/best-habit-tracking-apps/). 4.3★ from 3,484 US App Store ratings; more than 75,000 Google Play ratings. Habits, dailies and to-dos drive an RPG character (XP and gold for follow-through, health loss for misses). Dailies have checklists, difficulty and weekly schedules. - Streaks: 4.8★ from 27,349 US App Store ratings, $5.99 one-time, Apple-only. Supports negative tasks (habits to break), timed tasks, shared tasks, up to 24 tasks, Apple Health auto-completion (steps, workouts, mindful minutes), Watch logging, best streak, completion rate and a chart — [HabitKit guide](https://habitkit.app/help/guides/best-habit-tracker-apps). "1M+ downloads" is a third-party figure — [launchlify](https://launchlify.com/best-habit-tracking-apps/)
- Loop Habit Tracker: 5M+ downloads (Google Play), free, open source, Android-only — [launchlify](https://launchlify.com/best-habit-tracking-apps/); [HabitKit guide](https://habitkit.app/help/guides/best-habit-tracker-apps)
- Habitify: 3M+ downloads (third-party); 4.6★ from 7,139 US App Store ratings, 4.2 on Google Play. Timers, mood tracking, location reminders, "Off Mode" for holidays (pauses streaks), scores, heatmaps, auto-logging from Apple Health, Health Connect, Fitbit, Strava and Screen Time. Free tier: 3 habits with one reminder each — [HabitKit guide](https://habitkit.app/help/guides/best-habit-tracker-apps); [launchlify](https://launchlify.com/best-habit-tracking-apps/)
- Comparison habit apps with large rating volumes: TickTick (4.9★ from 46,263; yearly habit heatmap and widgets, habits bundled with tasks) and Daylio (4.8★ from 61,933; mood and activity journaling, "Year in Pixels"). HabitKit offers Yes/No, count, measured-unit habits and "quit" habits with a Stay Below limit, shown as a GitHub-style tile grid — [HabitKit guide](https://habitkit.app/help/guides/best-habit-tracker-apps)

### Inferences
- Among browser blockers, BlockSite has the most installs. Its free tier withholds scheduling, which suggests schedules are a monetizable core need. StayFocusd gives away Nuclear Option and still holds ~700K users, so locked mode alone is not a paid differentiator.
- The target extension's daily per-site limit already matches the core of StayFocusd and BlockSite. Gaps against them are schedules (active days/hours), a non-cancellable locked mode, a challenge before settings changes, path/keyword blocking, and in-page hiding of feeds/Shorts/recommendations.
- The One Sec data suggests a pause/friction screen with an explicit "close the site" button is among the best-evidenced, low-cost features to add. The dismiss option, not the message text, drives the effect.
- Rating volumes (Daylio 62K, TickTick 46K, Streaks 27K, Habitify 7K) suggest mood/journaling and habits bundled with tasks have large audiences.
- Body doubling (Focusmate) and adaptive audio (Brain.fm/Endel) are subscription businesses in their own right. In an extension they are more likely niche add-ons than table stakes.

### Gaps
- No usage figures found for Freedom, Cold Turkey, Focusmate, Brain.fm, Endel, Session, Flow, RescueTime, Rize, Toggl, Clockify or Timing in 2025–26. Opal's 4M figure is third-party and unverified.
- Timing (Mac) and Way of Life were not covered by any source found. Their features are unverified here.
- Chrome Web Store counts for the Forest, Freedom, RescueTime, Toggl and Clockify extensions were not retrieved.
- No source reported which features within an app are used most (feature-level telemetry). Reliance is inferred from feature lists, free/paid gating and reviews.
- Loop's features (it is known for score charts, heatmaps and numeric habits) were not confirmed by a fetched source.

## Q2. AI features shipped 2025–2026, and whether they are used

### Takeaway
AI is concentrated in automatic time trackers: Rize (focus score, AI-built schedules, auto-started sessions) and Toggl (autotrack, entry suggestions). Elsewhere it is thin: StayFocusd added Gen-AI chat usage analytics, Habitify added MCP so AI assistants can log habits, and Brain.fm and Endel use generative or adaptive audio. No source gave usage data for any AI feature. Blockers and habit apps mostly have none.

### Cited Findings
- Rize: AI builds tomorrow's schedule overnight and auto-starts focus, break and meeting blocks (vendor claim) — [Rize vs Timely](https://rize.io/blog/rize-vs-timely). Focus score, burnout detection, and a no-screenshots privacy model — [Rize/SaaS Trac review](https://rize.io/blog/rize-review-saastrac-ai-tracks-your-entire-workday)
- Toggl Track: AI entry suggestions, auto-categorization and autotrack — [aicentralresources](https://www.aicentralresources.com/blog/timely-vs-rescuetime-vs-toggl-best-ai-time-tracker-in-2026). Disputed as "no AI that builds drafts from your activity" — [aicentralresources ranking](https://www.aicentralresources.com/blog/8-best-ai-time-tracking-tools-in-2026-compared-priced-honestly-ranked)
- RescueTime: per one 2026 guide it "has not added" AI summaries, smart categorization or automated timesheets — [aicentralresources](https://www.aicentralresources.com/blog/8-best-ai-time-tracking-tools-in-2026-compared-priced-honestly-ranked). An AI-visibility site claims AI coaching based on "fatigue levels", which is unverified and likely inaccurate — [trakkr](https://trakkr.ai/ai-analysis/toggl-vs-rescuetime-ai-analysis)
- Clockify: AI minimal — [timely](https://www.timely.com/blog/toggl-track-alternatives/)
- StayFocusd: "Gen AI analytics for AI chat platforms", i.e. tracking time spent in ChatGPT-style tools — [SiteKeeper](https://www.sitekeeper.tech/compare/stayfocusd-vs-blocksite)
- Habitify: public API plus MCP support so an AI assistant can log habits and read stats — [HabitKit guide](https://habitkit.app/help/guides/best-habit-tracker-apps)
- Brain.fm: AI-generated functional audio. Endel: adaptive to context and biometrics. Freedom has no AI features beyond scheduling — [Asian Efficiency](https://www.asianefficiency.com/productivity/best-focus-deep-work-apps/)

### Inferences
- The most-cited AI value in time tracking is automatic categorization and summarization of passively collected data (focus score, deep vs shallow time). The target extension already collects per-site time, so an AI or rule-based "productive vs distracting" classifier plus a daily/weekly narrative summary is the closest feasible match.
- An "AI usage" category (time on ChatGPT, Claude etc.), as StayFocusd added, is a cheap, 2026-relevant addition.

### Gaps
- No adoption or usage metrics for any AI feature were found. Official 2025–26 changelogs for Toggl, RescueTime, Clockify, Opal and Forest were not retrieved, so ship dates are unconfirmed.

## Q3. What users praise, complain about, or request

### Takeaway
Praise centers on blocks you can't bypass (Cold Turkey, Freedom, Nuclear Option), accurate passive tracking (Rize), one-time pricing and Health auto-logging (Streaks), and friction that works (One Sec). Complaints center on easy bypass of browser-only and friction tools, overly aggressive blocking, subscription prices (Habitify, Opal, Brain.fm), confusing onboarding (Habitica), and weak cross-platform support (Opal on Android/Mac).

### Cited Findings
- Browser extensions and Screen Time are "too easy to bypass" for ADHD impulsivity (opinion from competitor FocusJar). LeechBlock is browser-only and can be defeated by switching browsers — [FocusJar](https://focusjar.app/articles/best-website-blockers-for-adhd); [AlternativeTo](https://alternativeto.net/software/cold-turkey)
- System-level enforcement that survives force-quit, restart or clock changes is the main point used to set Opal, Freedom and similar apps apart from friction apps — [habitdoom](https://habitdoom.com/blog/best-app-blocker-procrastination)
- Freedom complaints: "Sometimes overly aggressive… blocks legitimate sites"; interface "could use a redesign" — [Asian Efficiency](https://www.asianefficiency.com/productivity/best-focus-deep-work-apps/)
- One Sec: breathing prompt can be skipped and delays waited out — [unhookd](https://unhookd.app/blog/social-media-blocker-comparison)
- Forest: easy to quit by letting the tree die — [unstar.app](https://unstar.app/blog/opal-forest-freedom-one-sec-jomo-screen-time-apps-ranked-2026)
- Brain.fm complaints: no free tier, limited audio customization, "some people don't respond to it". Endel: needs Apple Watch for full adaptivity — [Asian Efficiency](https://www.asianefficiency.com/productivity/best-focus-deep-work-apps/)
- Habitify: price is the main theme of recent low-star reviews; sync requires an account. Habitica: confusing onboarding, features that changed or disappeared, ads on Android. Daylio: premium prompts and ads — [HabitKit guide](https://habitkit.app/help/guides/best-habit-tracker-apps)
- Opal: "great for phone, weak on Mac"; limited on Android — [tryhugo](https://www.tryhugo.app/blog/opal-app-review-2026); [habi.app](https://habi.app/insights/best-screen-time-apps/)
- Rize praise: accurate passive tracking, clean design, focus/distraction insights, flexible timers, break prompts, background audio. Con: "limited features" — [Product Hunt](https://www.producthunt.com/products/rizeio/reviews); [toolradar](https://toolradar.com/tools/rize)
- StayFocusd: a reported drop in recent ratings linked to a block-list bug and privacy concerns (single-source) — [web-highlights](https://web-highlights.com/blog/best-website-blocker-chrome-extensions/)
- Compliance is a core problem even in a study: only 25.5% of committed participants complied with a 2-week Freedom block — [PNAS Nexus](https://academic.oup.com/pnasnexus/article/4/2/pgaf017/8016017)

### Inferences
- A Chrome extension can't match OS-level enforcement. Its best defenses are a locked/nuclear mode, a challenge or password to change settings or disable, and a friction screen, and it should be honest that switching browsers bypasses it.
- Privacy (local-only data, no account required, as with HabitKit, Daylio and Streaks) and one-time or generous free pricing are recurring praise points and fit a small-team extension.

### Gaps
- Direct Reddit threads (r/nosurf, r/ADHD, r/productivity) were not retrieved; the search returned comparison pages instead. No 2025–26 user survey on feature preferences was found. Zapier, The Verge and Wirecutter blocker or habit reviews were not fetched, apart from Zapier's Pomodoro roundup as a link.

## Q4. Table stakes vs differentiators

### Takeaway
For a 2026 focus/blocking/habit extension, the table stakes are: block lists, schedules, daily time limits, a Pomodoro/focus session that triggers blocking, basic usage stats, streaks, reminders and count/timed habits. Differentiators are: an uncancellable locked mode, friction/pause screens with a dismiss option, in-page feed hiding, automatic productive/distracting categorization with a focus score, gamification (trees, gems, RPG), negative/quit habits with limits, heatmaps, mood journaling, ambient sound, body doubling and AI summaries.

### Cited Findings
- Present in nearly every blocker reviewed: block lists, schedules, daily limits and session-triggered blocking — BlockSite, StayFocusd, Freedom, Session and Flow Pro all include them — [SiteKeeper](https://www.sitekeeper.tech/compare/stayfocusd-vs-blocksite); [Asian Efficiency](https://www.asianefficiency.com/productivity/best-focus-deep-work-apps/); [apps.deals](https://blog.apps.deals/best-pomodoro-timer-apps-mac)
- Lock modes: StayFocusd Nuclear Option (free), Freedom Locked Mode, Cold Turkey lock blocks, Flow Commitment Mode — [SiteKeeper](https://www.sitekeeper.tech/compare/stayfocusd-vs-blocksite); [Asian Efficiency](https://www.asianefficiency.com/productivity/best-focus-deep-work-apps/); [apps.deals](https://blog.apps.deals/best-pomodoro-timer-apps-mac)
- Friction: One Sec pause (57% fewer opens, 2023 study), Rize 10-second urge-surfing delay — [PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC9974409); [dhruvirzala](https://dhruvirzala.com/rize-review/)
- In-page hiding of Shorts, comments and recommendations: StayFocusd — [SiteKeeper](https://www.sitekeeper.tech/compare/stayfocusd-vs-blocksite)
- Session journaling (intentions before, reflection after): Session — [Zapier](https://zapier.com/blog/best-pomodoro-apps/); [apps.deals](https://blog.apps.deals/best-pomodoro-timer-apps-mac)
- Habit types commonly offered by top-rated habit apps: count/measured, timed, negative/quit with limits, weekly schedules, vacation/Off mode, heatmaps and grids, Health auto-logging — [HabitKit guide](https://habitkit.app/help/guides/best-habit-tracker-apps)
- Gamification variants: Forest trees and coins, Opal gems and leaderboards, Habitica XP/HP and parties — [Wikipedia](https://en.wikipedia.org/wiki/Forest_(application)); [screensdesign](https://screensdesign.com/showcase/opal-screen-time-control); [HabitKit guide](https://habitkit.app/help/guides/best-habit-tracker-apps)
- Focus score and deep vs shallow classification: Rize — [Rize](https://rize.io/l/ai-time-tracker)
- Idle detection and project time logging: Toggl Track, Clockify — [aicentralresources](https://www.aicentralresources.com/blog/timely-vs-rescuetime-vs-toggl-best-ai-time-tracker-in-2026); [trakkr](https://trakkr.ai/ai-analysis/clockify-vs-rescuetime-ai-analysis)

### Inferences (ranked candidates for the target extension, given it already has Pomodoro, streak habits and per-site time with daily limits)
1. Block schedules (days/hours) and focus sessions that auto-block a list. This is table stakes, and BlockSite charges for it.
2. A friction/pause screen with an explicit "close tab" option on limited sites. It has the strongest evidence base and is cheap to build.
3. Locked/nuclear mode plus a challenge before disabling or editing. Users expect it and competitors give it away free.
4. Productive/distracting categorization of tracked sites, a daily focus score, and a weekly report. This brings the existing tracker in line with RescueTime and Rize, and AI can help auto-label domains.
5. Richer habit types: count, timed, negative/quit with a limit, weekly targets, skip/vacation days that keep streaks, and a yearly heatmap.
6. In-page distraction hiding (YouTube Shorts, recommendations, feeds). StayFocusd shows demand.
7. Optional extras: ambient sounds, light gamification (session-based growth), a session intention and reflection note, and an "AI tools" usage category.
- Lower priority for a small extension team: live body doubling (needs infrastructure and video), adaptive biometric audio, and client/project billing (Clockify and Toggl's core market differs).

### Gaps
- No quantitative data ranks which of these features drive retention or conversion. The ranking above is inferred from feature prevalence, free/paid gating, review themes and the One Sec and Freedom studies.
