# Chrome Productivity Extensions & New-Tab Dashboards (2025–2026): Users, Ratings, Features, Chrome Overlap, Policy

Research date: 18 Nov 2026. Main user-count source: chromeextensions.org's "Top 500 by users" ranking, scraped from the Chrome Web Store and dated **17 Nov 2026**. The Chrome Web Store (CWS) rounds user counts to the leading digit (e.g. "2M" can mean anything from 2,000,000 to 2,999,999). CWS "users" means weekly active installs, not people who actively use a feature. A small model extracted the ranking tables, so a few rating-count figures may have been transcribed wrongly (see Gaps).

## Q1. Which extensions have the most users and the best ratings?

### Takeaway
The extensions with the most users are writing/AI assistants (Grammarly 40M, Claude 23M, ChatGPT 9M, QuillBot 6M, Sider 5M), translation (Google Translate 39M), screenshot/recording tools (GoFullPage 11M, Screencastify 9M, Loom 8M), password managers and Dark Reader (7M). New-tab dashboards and tab managers are much smaller: Momentum and OneTab have about 2M each, Session Buddy about 1M, and every other new-tab dashboard has fewer than 700K users. Among the large extensions, GoFullPage (4.9), Sider (4.9), FireShot (4.9) and Tampermonkey (4.8) have the best ratings. LastPass (1.8), Loom (2.7), Bitwarden (2.8) and Notion Web Clipper (2.9) have the worst.

### Inferences
- **AI and writing assistance is the largest productivity category.** Claude (23M) is more than double ChatGPT (9M) in Chrome. Multi-model sidebars (Sider 5M, Monica 3M, Merlin 900K, MaxAI 700K) are also substantial. ProdLi's AI chat already competes here, but it lives on the new tab, while the big players run as a sidebar on every page.
- **Screenshot capture is a strong candidate to add.** GoFullPage (11M, 4.9) and FireShot (3M, 4.9) have very high ratings because they do one thing well. Loom's 2.7 rating suggests users dislike heavy, account-gated tools.
- **New-tab dashboards are a niche.** Momentum's ~2M users is the ceiling. The well-loved ones (Bonjourr 4.9) win on being free, private and account-free.
- **Session Buddy (3.3) and OneTab (3.8) are widely used but poorly rated.** That points to unmet demand for reliable tab saving.
- **Some rating counts look unusual and should be checked by hand.** Sider has ~115K ratings on 5M users, about 10 times the ratio of comparable extensions. That may reflect in-app rating prompts.

## Q2. Which features drive usage?

### Takeaway
Usage centres on a small set of jobs:
- one-click writing help and grammar checks on every page
- translating pages and selections
- full-page screenshots, and screen recording with sharing
- AI chat or summaries of the current page and across tabs
- saving and restoring tab sessions
- web clipping into a notes app
- autofilling passwords
- dark mode
- blocking distracting sites

On new tabs, the core is a clean background, clock/greeting, focus, to-dos, links and search. Users push back when these basics move behind paywalls or sign-in.

### Cited Findings
- **Tab saving and sessions:**
  - OneTab (2M) and Session Buddy (1M) are the largest tab managers — [chromeextensions.org](https://www.chromeextensions.org/top/3/)
  - Toby and Workona (each 200K+) add workspaces and tab collections, and Toby charges per workspace — [Leap](https://leap-tabs.com/blog/best-tab-managers-chrome-2026)
- **Read-later:** Pocket's closure (8 July 2025) sent users to these replacements — [AlternativeTo](https://alternativeto.net/news/2025/5/after-17-years-mozilla-is-shutting-down-the-popular-bookmarking-tool-pocket-and-fakespot), [9to5Mac](https://9to5mac.com/2025/05/28/pocket-read-it-later-alternatives/), [web-highlights](https://web-highlights.com/blog/pocket-shuts-down-in-july-2025-the-10-best-alternatives/)
  - Raindrop.io: unlimited bookmarks, collections, reader mode, and import of Pocket's HTML export
  - Readwise Reader: highlights plus reading, about $8–10/month
  - Matter: mobile-first reading
  - Instapaper: simple offline reading
  - Wallabag: self-hosted
- **Clipping:**

- **Screenshots and recording:** GoFullPage (11M), FireShot (3M), Awesome Screenshot (4M) and Lightshot (2M) are capture + annotate tools. Screencastify (9M) and Loom (8M) record video — [chromeextensions.org](https://www.chromeextensions.org/top/)
- **Meeting notes:** Tactiq (1M, 4.9) transcribes Google Meet, Zoom and Teams. This is directly comparable to ProdLi's Meet notes — [chromeextensions.org p3](https://www.chromeextensions.org/top/3/)

- **AI sidebars:**
  - Sider's listing name itself advertises multi-model chat ("GPT-5, Claude, DeepSeek, Gemini, Grok") — [chromeextensions.org](https://www.chromeextensions.org/top/)

### Inferences
- **Highest-value gaps for ProdLi, judging by user numbers and fit with a new-tab hub:**
  1. Tab session save/restore (OneTab/Session Buddy demand, plus their poor ratings)
  2. A read-later list with highlights (Pocket/Omnivore refugees)
  3. Full-page screenshot + annotate saved into ProdLi
  4. Page/selection translation and summary through the existing AI chat
  5. Site blocking linked to the Pomodoro timer
  6. Quick links/speed dial and a search bar on the new tab
- **Background, quote and weather widgets are expected by default.** They are commodity features rather than reasons to install.

## Q3. What did Chrome add in 2025–2026 that makes some extension features redundant?

### Takeaway
Since September 2025, Chrome has built in features that overlap with these extensions:
- Gemini in Chrome: summarise/explain pages, compare across tabs, recall past pages, agentic "auto browse", Calendar/YouTube/Maps actions
- AI Mode in the address bar
- a password-change agent
- split view (Feb 2026)
- vertical tabs and a full-window reading mode (Apr 2026)
- saved, synced tab groups

Together these weaken simple AI summarisers, split-screen tools, basic reader-mode extensions and light tab-group managers.

### Cited Findings
**18 Sept 2025 release** — [Google blog: "Go behind the browser with Chrome's new AI features"](https://blog.google/products-and-platforms/products/chrome/new-ai-features-for-chrome/), [TechCrunch](https://techcrunch.com/2025/09/18/google-brings-gemini-in-chrome-to-us-users-unveils-agentic-browsing-capabilities-and-more/?rand=324)
- Gemini in Chrome rolled out to US Mac and Windows users with English set as the language.
- What it does: explains a page, compares and summarises across tabs, and works with Calendar, YouTube and Maps.
- Announced as "coming": recalling past tabs and agentic browsing.
- AI Mode in the omnibox, with questions about the current page shown in a side panel.
- Gemini Nano scam detection.
- A one-click password-change agent ("very soon").
- Available to users 18+ in select countries.

**Later Gemini update (Gemini 3 / auto browse)** — [Google blog: "Putting Gemini to work in Chrome"](https://blog.google/products-and-platforms/products/chrome/gemini-3-auto-browse/)
- Gemini sits in a side panel that stays open across tabs.
- "Auto browse" fills forms (e.g. from a PDF).
- Chrome will support Google's Universal Commerce Protocol.
- The exact post date wasn't confirmed.

**Press reception**
- Full agentic browsing is limited to paid tiers — [Tom's Guide](https://www.tomsguide.com/ai/google-is-rolling-out-the-biggest-changes-to-chrome-in-years-heres-whats-changing)
- Testers found agentic features slow, while the sidebar and multi-tab context were strong — [Android Authority](https://www.androidauthority.com/gemini-in-chrome-sidebar-test-3636732/)

**Other Chrome features**
- Vertical tabs ("Show Tabs Vertically") and a full-page reading mode ("Open in reading mode") began rolling out on 7 Apr 2026 — [Google blog](https://blog.google/products-and-platforms/products/chrome/new-chrome-productivity-features/), [Android Authority](https://www.androidauthority.com/chrome-vertical-tabs-stable-3655470/)
- Split view (two tabs side by side in one window) was announced on 19 Feb 2026. This comes from a secondary source citing Google — [thetabextension.com](https://thetabextension.com/blog/best-browsers-tab-management-2026)
- Saved tab groups sync across signed-in devices, but unsaved groups don't. This is a secondary guide — [Supercharge Browser guide](https://www.superchargebrowser.com/library/chrome-tab-groups-complete-guide/)

### Inferences
- **Weakened by Chrome:**
  - basic "summarise this page" or "chat with page" AI features, at least in the US for English users
  - split-screen extensions (e.g. Tab Resize, 1M)
  - simple reader-mode extensions
  - simple tab-grouping
- **Still differentiated:**
  - cross-browser or exportable session archives
  - read-later with highlights and notes
  - full-page screenshots with annotation
  - meeting transcripts
  - time tracking
  - the focus timer combined with site blocking
  - multi-model AI choice
  - local or private data storage
- **ProdLi should frame its AI as working on the user's own notes and saved items** rather than as a generic page summariser.

### Gaps
- I found no confirmation of a 2025–26 Chrome "AI tab organizer" update; Chrome's tab organizer feature dates from 2024 (older data, not re-verified).
- Gemini in Chrome availability outside the US/English in late 2026 wasn't confirmed.
- Exact rollout dates for the Gemini 3 / auto browse post and for split view weren't confirmed from primary sources.

## Q4. What do users praise, complain about, or request? Privacy, sales, removals

### Takeaway
Users praise tools that are free, fast, private and focused (Bonjourr, GoFullPage, Dark Reader). They complain about:
- features moving behind paywalls and forced sign-in (Momentum, Toby)
- data loss in tab managers (OneTab)
- shutdowns of read-later apps (Pocket, Omnivore)

The biggest trust issue is extensions that turn malicious through auto-updates after building a user base. That includes ShadyPanda in Dec 2025, which reportedly involved new-tab extensions.

### Cited Findings
- **Momentum:** the most-criticised theme in recent reviews is paywall placement (20 of 44 mentions negative). Some users are wary of Google sign-in on the new tab. No permission or publisher changes are on record — [Tooltivity Momentum review](https://tooltivity.com/extensions/momentum)
- **OneTab:**
  - In Feb 2026, a storage migration timed out and many users opened OneTab to an empty page. There are reports of lists vanishing after restarts or updates — [Tooltivity OneTab review](https://tooltivity.com/extensions/onetab)
  - A commenter warns that "share as web page" uploads tab lists to OneTab's servers. This is a user comment, not verified — [Substack comments](https://beyondthefirewall.substack.com/p/99-of-people-using-these-browser/comments)
- **Toby:** added a free-tier limit of 60 tabs and per-workspace pricing — [Leap](https://leap-tabs.com/blog/best-tab-managers-chrome-2026)
- **Tabliss:** praised but reportedly unmaintained since 2022 — [Dashy](https://www.dashyapp.com/blog/best-new-tab-extensions-2026)
- **Bonjourr:** praised for having nothing to buy and collecting nothing — [Dashy](https://www.dashyapp.com/blog/best-new-tab-extensions-2026)
- **Shutdowns:**
  - Pocket shut down on 8 July 2025 — [AlternativeTo](https://alternativeto.net/news/2025/5/after-17-years-mozilla-is-shutting-down-the-popular-bookmarking-tool-pocket-and-fakespot)
  - The data-export deadline is reported as 8 Oct 2025 by some sources and 12 Nov 2025 by others (they conflict) — [web-highlights](https://web-highlights.com/blog/pocket-shuts-down-tomorrow-everything-you-need-to-know.md)
  - Omnivore shut down in Nov 2024 after an ElevenLabs acqui-hire (older data, outside 2025–26) — [9to5Mac](https://9to5mac.com/2025/05/28/pocket-read-it-later-alternatives/)
- **ShadyPanda (reported by Koi Security, Dec 2025):** 4.3M Chrome/Edge users were affected over 7 years.
  - Extensions built trust, then pushed updates that checked a server every hour and ran arbitrary JavaScript, exfiltrating browsing data.
  - Updates arrived silently through auto-update.
  - WeTab (a new-tab extension) is named, with ~3M Edge downloads.
  - Google says none of the extensions remain on the CWS.
  - Sources — [The Register](https://www.theregister.com/2025/12/01/chrome_edge_malicious_browser_extensions/), [Infosecurity Magazine](https://infosecurity-magazine.com/news/shadypanda-infects-43m-chrome-edge), [SC World](https://www.scworld.com/news/shadypanda-exploited-chrome-edge-browser-extensions-for-7-years)
- **Infinity New Tab:** one outlet reports its publisher was linked to ShadyPanda in Dec 2025. This is unverified, and the primary report should be checked — [Dashy](https://www.dashyapp.com/blog/best-new-tab-extensions-2026)
- **PayPal Honey:** lost about 3M of its 20M users within two weeks of the late-2024 affiliate allegations. It is a shopping extension, but the case shows how trust collapses — [Wikipedia: PayPal Honey](https://en.wikipedia.org/wiki/PayPal_Honey)
- **Low ratings among large extensions:** LastPass 1.8, Loom 2.7, Bitwarden 2.8, Notion Web Clipper 2.9 and Google Translate 3.0 have low ratings despite large user bases — [chromeextensions.org](https://www.chromeextensions.org/top/)

### Inferences
- **ProdLi can turn trust into a selling point:**
  - local-first storage and one-click export
  - no forced account
  - clear permission explanations
  - a public changelog
  - a commitment not to sell the extension or data
- **Data-loss stories make reliable session backup and export a differentiator for tab saving.**
- **Paywalling core new-tab basics (focus, to-dos, backgrounds) creates backlash.** Monetising advanced or AI features carries less risk.

### Gaps
- No Reddit threads came back in search, so I couldn't quote r/chrome or r/productivity directly. Complaint themes come from review aggregators and blog reviews, which may be biased.
- The Infinity–ShadyPanda link needs verification against Koi Security's original report.

## Q5. Chrome Web Store policy constraints relevant to adding these features

### Takeaway
The single-purpose policy is the main risk for an "all-in-one" extension. Google accepts "new tab page" as a narrow browser function, and features delivered inside the new tab (including AI chatbots) appear to be acceptable. But the action button of a new-tab extension "cannot introduce any additional functionality". Broad multi-purpose toolbars and injected UI are discouraged or disallowed. Search on the new tab must respect the user's default engine. Permissions must be the narrowest possible, browsing-activity collection must be limited to disclosed, user-facing features, and no remote code is allowed under MV3.

### Cited Findings
**Single purpose** — [CWS Quality Guidelines FAQ](https://developer.chrome.com/docs/webstore/program-policies/quality-guidelines-faq)
- "Single purpose" can mean either a narrow subject (e.g. weather) or a narrow browser function (e.g. "new tab page" or "tab management").
- "Excessive permissions unrelated to your extension's single purpose will be viewed as enabling unrelated functionalities."

**New-tab extensions** — [CWS Quality Guidelines FAQ](https://developer.chrome.com/docs/webstore/program-policies/quality-guidelines-faq)
- They may include AI chatbots or vertical search (e.g. searching open tabs).
- Web search must follow the user's default through the Chrome Search API.
- Changing the search provider counts as a separate function and shouldn't be coupled with other features.
- An action button may be a shortcut to the main feature, but it "cannot introduce any additional functionality or content."
- "Broad, multi-purpose toolbars are not allowed."
- Content-script toolbars injected into every page are discouraged; an action popup is recommended instead.
- Non-compliant extensions can be removed or auto-disabled, with their settings reverted.

**Program policies** — [CWS Program Policies](https://developer.chrome.com/docs/webstore/program-policies/policies)
- Extensions must "request access to the narrowest permissions necessary". Don't request permissions for features that aren't built yet.
- The new tab must be replaced through the URL Overrides API.
- Browsing activity may only be collected for a user-facing feature that is clearly described.
- Data use is limited to the single purpose. Selling data or using it for personalised ads is prohibited.
- A Limited Use affirmation is required on the website.
- Extensions need a privacy policy, prominent disclosure, and affirmative consent. Data practices that change after install must be disclosed prominently.
- Page content sent to AI servers counts as user data, so these rules apply to it. There is no AI-specific rule.
- MV3: all logic must be in the package. `eval()` on remotely fetched strings is a violation. Remote configuration is allowed only for logic that ships in the package.
- Ads must be removable. Affiliate programs must be disclosed prominently and need related user action.
- There is no general rule on ownership changes. Transferring data in a sale or merger requires explicit prior user consent.

### Inferences
- **Features that sit comfortably inside a "new tab page" purpose:** speed dial, search bar (using the user's default engine), weather, quotes, backgrounds, to-dos and notes, read-later list, session list, and AI chat.
- **Features that need "all websites" host access are where single-purpose and permission scrutiny is highest:**
  - in-page translation overlays
  - highlighters
  - screenshots of arbitrary pages
  - site blocking
  - website time tracking (which ProdLi already has)
- Safer patterns:
  - use `activeTab` (granted only on a user gesture) rather than `<all_urls>`
  - use `optional_host_permissions` requested at the moment a feature is turned on
  - use the context menu and the side panel triggered by the user
- **ProdLi's existing context-menu "save to ProdLi" and Meet notes should be documented as feeding the new-tab hub.** That framing keeps them inside one purpose. ProdLi should avoid making the toolbar popup a separate mini-app.
- A tab-session manager may be arguable as "tab management". Framing it as "sessions you resume from your new tab" keeps it inside the new-tab purpose.

### Gaps
- I found no published enforcement cases showing where Google draws the line for "all-in-one productivity" new-tab extensions. How strictly the rule is applied is unclear.
- The policy says nothing specific about the side-panel API. The general single-purpose test applies.
